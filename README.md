# Great Things

This site uses GitHub Pages at https://great-things.ai. US English is the default language. Visitors can choose Spanish, Portuguese, Chinese, Hebrew, US English, or UK English from the flag menu. Each choice has a shareable `?lang=` URL, such as `?lang=he` or `?lang=es`.

To preview the site, run `python3 -m http.server 4173` from this directory and open http://localhost:4173.

The public Calendly event URL is in `config.js`. The site does not need a Calendly access token. Keep access tokens out of this repository.

GitHub Pages serves the files from the root of the `main` branch. The `CNAME` file sets the custom domain.
